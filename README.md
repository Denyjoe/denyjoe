## Selected work

### [vdi](https://github.com/Denyjoe/vdi)
Cloud-based virtual computing lab for universities in East Africa. Students open a browser and get a real Linux or Windows desktop running on shared Proxmox VE hardware, billed per hour or by subscription through M-Pesa, Airtel Money, Tigo Pesa, and Halopesa. It also runs live proctored sessions with network lockdown and broadcast messaging for lecturers.

### [CertifyChain](https://github.com/Denyjoe/BlockchainBasedResultsManagement)
Decentralized student result verification. Report cards are hashed and registered on the Ethereum blockchain; uploading a report card later recomputes the hash against the on-chain record, so any tampering is caught immediately.

### [SocialUp](https://github.com/Denyjoe/SocialUp)
Wallet-funded SMM panel built for the Tanzanian market. Customers fund a wallet in TZS and order followers, views, and likes from a catalog synced live from an upstream provider, paying with crypto through NOWPayments.
